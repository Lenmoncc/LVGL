# LVGL
本LVGL仓库是在i.MX6ULL开发板上运行，整体功能与界面布局均根据个人需求定制开发。
- EnvMonitor：LVGL官方历程，包含基础的音乐播放控制界面与交互逻辑；
- MusicPlayer：为个人独立设计的UI模块，包含环境参数的实时显示。
